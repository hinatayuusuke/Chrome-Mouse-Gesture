# GestureMaster (Chrome拡張)

マウスジェスチャー（右クリックの軌跡）と、スーパードラッグ（リンク/テキスト/画像のドラッグ方向）で操作を行う Chrome 拡張です。

## 主な機能

- **マウスジェスチャー（右クリック）**
  - 戻る / 進む / 更新
  - ページ先頭 / 最下部へスクロール
  - タブを閉じる / 閉じたタブを復元
  - 新しいタブを開く
  - タブを左右へ移動
- **スーパードラッグ（ドラッグ方向で実行）**
  - リンク: 新規タブ（前面/背面）で開く、シークレットで開く、URL/テキストをコピー
  - テキスト: Google検索
  - 画像: 新規タブ（前面/背面）で開く、シークレットで開く、画像URLをコピー
- **外観・感度の調整**
  - 線の色/太さ/透明度
  - 最小認識距離、角度許容
- **除外リスト**
  - 指定サイトではジェスチャーを無効化（ワイルドカード `*` 対応）
- **設定のインポート/エクスポート**
  - JSONでバックアップ、共有

## インストール（開発版 / 手動）

1. このリポジトリを取得します
2. Chrome の拡張機能ページを開きます: `chrome://extensions`
3. 右上の **デベロッパーモード** を ON
4. **パッケージ化されていない拡張機能を読み込む** → このフォルダを選択

## 使い方

### マウスジェスチャー

- 右クリックを押したままマウスを動かし、ボタンを離すと実行されます
- キャンセル: 軌跡を描いた後に開始点付近へ戻る、または `Esc`

### スーパードラッグ

- リンク/選択テキスト/画像をドラッグして方向を付けると実行されます
- 方向ごとの動作はオプション画面で変更できます

## 設定

拡張のオプション画面（`chrome://extensions` → GestureMaster → 詳細 → 拡張機能のオプション）から編集できます。

- ノーマルジェスチャー: 右クリック軌跡とアクションの対応
- スーパードラッグ: コンテキスト（リンク/テキスト/画像）×方向の対応
- 外観・感度: 線の見た目、判定感度
- 除外リスト: 例 `example.com` / `https://example.com/*` / `*://*.example.com/*`

## シークレットウィンドウで開くについて

スーパードラッグの「シークレットウィンドウで開く」は、Chrome 側で拡張機能の **シークレットモードでの実行を許可** している必要があります。

1. `chrome://extensions` を開く
2. GestureMaster の **詳細**
3. **シークレットモードでの実行を許可** を ON

許可されていない場合、シークレットウィンドウの作成に失敗します（通常タブへフォールバックはしません）。

## 権限について

`manifest.json` で以下を使用しています。

- `tabs` / `activeTab`: タブ操作（作成/移動/クローズ等）
- `sessions`: 閉じたタブの復元
- `clipboardWrite`: クリップボードへのコピー
- `storage`: 設定の保存
- `host_permissions: <all_urls>`: コンテンツスクリプトで全サイトの入力を検知するため

## 開発メモ

- `content.js`: 入力検知、方向判定、描画、設定反映
- `background.js`: タブ操作（Service Worker）
- `options.html` / `options.js`: 設定UI
